# LaunchShield

LaunchShield 是一个 iOS 去开屏广告工具：找出其他应用缓存的开屏广告素材，先备份，再原地清成 0 字节并冻结，让开屏广告出不来。清掉的素材都有备份，随时可以还原。

当前正式版 0.1.8，预发行版 0.2.0，最低系统 iOS 26.0，SwiftUI。

## 功能

- **跨应用文件通道**：移植 kolbicz/WQFiles 的 WQAccess 容器访问层（worse_query 技术），不使用 dylib 注入。
- **应用列表**：按 iOS 26.1 的真实格式解析系统数据库，应用名正常显示、秒出结果；少数应用（如 QQ）的名字在系统库里没有，仍显示应用 ID。目标应用列表不显示系统应用。
- **选应用**：可以单个选，也可以批量选；LaunchHack 只对单个应用检测。
- **素材扫描**：按云端广告规则名单扫描已知广告目录，命中的按广告商分类列成清单；规则现为第 8 版，覆盖 22 个分组、249 个广告目录、72 个关键词（优量汇、穿山甲、BeiZi、美数、UBIX、趣盟、AdMob、TradPlus、Mintegral、软件自营等）；「深扫」再翻一遍名单之外的疑似素材。
- **规则更新**：广告规则由服务器下发，不用更新应用本身；打开应用时会自动检查，也可以随时手动更新。
- **文件夹优先处理（治「清完又长」）**：清零时把素材所在文件夹的文件一起备份、清零、冻结，并把文件夹登记为「文件夹守护」；以后新广告再落回这个文件夹，打开 LaunchShield 时会自动一并清掉。只有系统大缓存区这类太宽的文件夹不整夹，里面的文件仍可单文件清零。
- **已守护应用**：按应用折叠列出守护中的文件和文件夹，能单独结束守护（结束时先解冻）；删除备份会先把备份恢复回去、成功了才删，恢复不了的那份留着不删。
- **LaunchHack（自己认图找广告）**：扫描选中的应用，把大图（短边 300 像素以上）、视频、动图和成套的 Lottie 动画、网页广告包列成一面墙：视频点开能播、动图会动、成套的按整个文件夹列出内容。你认出哪个是广告就标记哪个，标记自动同步到主页素材清单，在那里统一清零、冻结。机器按证据查到的数据不展示，上传时作规则原料一并带上。
- **备份管理**：备份按应用归并查看，可按应用还原或删除；「全部还原」遇到还原不了的文件会跳过并继续，最后汇总告知。
- **文件工具**：大文件榜和按文件名搜索，每个文件带人话标签（疑似广告 / 图片·视频 / 个人内容 / 应用文件）；聊天应用账号目录里的图片、视频是个人内容，一律绕开，不会误清。
- **数据上传**：识别数据、配置文件快照和运行日志可以上传到收集箱，用来核对并扩充广告规则；上传只在用户点按时发生，只读不改文件。
- **检查更新**：正式版只查正式版，预发行版只查预发行版；有新版会在应用内提醒并可直接下载。更新公告取自正式版发行说明。
- **使用教程**：应用内有图文教程（如何使用、LaunchHack、已守护应用）。
- **日志**：记录每个文件的结果与失败原因，可复制全部，也可导出（导出内容带系统版本、应用版本、设备和共享组）；日志文件自动封顶，只留最近的部分。
- **已知边界**：少数应用的开屏由服务器实时下发、素材不落到手机里，这类开屏用文件办法处理不了；先下盘再播的应用都有效。

## 签名要求（重要）

- 支持范围：iOS 26.0–26.7.2（正式版）、iOS 27.0–27.2（正式版）和 iOS 27.3 beta 1。iOS 27.3 beta 2 起，系统挡住了 worse_query，不再支持。
- 证书签名：直接可用。
- 免费 Apple ID 签名：如果签名给应用带上了可用的 App Group，也能用；没有可用组时，只有 iOS 26.0–26.6.1（正式版）能走备用通道，其他版本会明确提示不支持，不会静默失败。
- 通道按运行时实际拿到的 App Group 权限判定，不按签名工具名称判定；拿不到权限时界面会显示具体原因。

## 构建

- 云端：正式版通过 GitHub Actions 的 `workflow_dispatch` 手动触发；运行时手动填写 App 版本号和构建号，默认保留所有历史正式版 Release、Tag 和 IPA。见 `.github/workflows/build.yml`。
- 本地：用 Xcode 打开 `LaunchShield.xcodeproj`，选择 `LaunchShield` scheme，Release，真机或 generic iOS 设备。
- 应用图标在 `LaunchShield/Assets.xcassets/AppIcon.appiconset`，浅色与深色两版均由 `IconDesigns/` 的成品接入。

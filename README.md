# LaunchShield

LaunchShield 是一个 iOS 启动素材管理工具的界面原型，目前版本为 0.1.0（测试版）。

## 当前阶段

本次提交只实现 SwiftUI 应用骨架与界面，不包含跨应用文件访问能力。扫描、备份、清零和还原按钮会明确提示尚未接入，不会修改目标应用数据。

## 界面内容

- 目标应用：百度网盘（`com.baidu.netdisk`）
- 素材来源分类：百度自营、优量汇、穿山甲、BeiZi
- 文件总数、待清理数量、备份数量摘要
- 全部清零与全部还原操作入口
- 运行日志与复制日志入口

## 构建

使用 Xcode 打开 `LaunchShield.xcodeproj`，选择 LaunchShield scheme，目标为 iOS 26.0 或更新版本。

当前阶段不触发云端构建。待完整实现与检查完成后，再按约定一次性推送并触发最终构建。
